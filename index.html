대분류 설정

보드 안에서는 대분류 이름을 바꾸지 않습니다. 여기에서 표시 이름을 수정하거나 새 대분류를 추가할 수 있습니다.

사용방법

1. 업무보드 이름

왼쪽 상단 업무보드 이름 옆의 작은 회색 ✎를 눌러 ‘김우중의 업무보드’처럼 원하는 이름으로 바꿀 수 있습니다.

2. 업무 작성

제목은 10.02 | 분류 | 내용 형식으로 작성합니다. 제목 입력창에서 스페이스바를 두 번 누르면 | 가 자동 입력됩니다. 형식이 맞지 않아도 저장되지만 빨간색으로 수정 필요 상태가 표시됩니다.

3. 대분류 보드

기본 5개 대분류 보드를 제공하며 상단 ⚙ 대분류 설정에서 이름을 수정하거나 새 대분류를 추가할 수 있습니다. 이름을 바꿔도 기존 업무와 색상은 유지됩니다. 보드는 드래그하여 순서를 바꿀 수 있고, -1·기본·+1·+2·+3의 5단계로 폭을 조절합니다.

4. 할 일 관리

○를 눌러 완료 처리합니다. 완료한 업무는 바로 사라지지 않으며, 필요할 때 ⋮ 메뉴의 완료됨으로 이동을 눌러 보드 하단의 서랍으로 직접 옮깁니다. 날짜가 지난 완료 업무가 아직 서랍으로 이동되지 않았다면 적갈색으로 표시됩니다. ☆를 누르면 중요 업무로 별표 표시되며 ★ 별표 업무에서 모아볼 수 있습니다. 할 일 카드를 드래그해 같은 보드의 위·아래 또는 다른 보드로 이동할 수 있습니다. 제목·메모 글자 위에서는 텍스트 선택과 편집이 우선되며 카드가 움직이지 않습니다. 특히 수정 모드의 입력창 안에서 마우스를 끌면 텍스트만 선택되고 업무 카드나 보드 이동은 시작되지 않습니다. 편집 중 ESC를 누르면 빈 공간을 클릭한 것처럼 수정 모드가 종료되고 입력 내용이 저장됩니다.

5. 메모·고정·정렬

업무 메모는 전체 내용이 표시되며 메모를 더블클릭하면 바로 수정할 수 있습니다. 고정 업무는 항상 보드 상단에 유지됩니다. 각 보드의 정렬 메뉴에서 수동순서 / 최신순 / 과거순을 선택할 수 있으며 기본값은 최신순입니다.

6. 날짜별 할 일

상단 날짜별 할 일에서 를 대분류 색상 태그와 함께 모아봅니다. 업무 카드는 마우스로 드래그해 위·아래 순서를 직접 바꿀 수 있으며, 삽입 위치는 카드 사이의 파란색 선으로 표시됩니다. 날짜별 화면에서 정한 순서는 원래 대분류 보드 순서와 별도로 저장됩니다. 패널은 오른쪽 벽에 붙어 열리고 -1·기본·+1·+2·+3으로 크기를 바꿔도 오른쪽 정렬을 유지합니다. 패널을 직접 드래그한 뒤에는 사용자가 옮긴 위치를 기준으로 유지합니다. 우측 상단의 큰 X 버튼과 넓은 클릭 영역으로 패널을 쉽게 닫을 수 있습니다.

7. 주간보고

주간보고에서 선택한 주의 완료업무, 미완료·이월, 차주 예정 업무를 자동 집계하고 보고서 텍스트를 복사할 수 있습니다.

8. 완료됨 서랍

완료 업무가 생기면 보드 하단에 완료됨(개수) 서랍이 나타납니다. 완료 체크한 업무는 ⋮ 메뉴뿐 아니라 마우스로 완료됨 서랍에 드래그하여 직접 옮길 수 있습니다. 업무를 드래그할 때 실제 삽입 위치는 카드 사이의 파란색 선으로 표시됩니다. 앞의 큰 화살표 또는 제목 영역을 눌러 접거나 펼칠 수 있습니다.

9. 오늘의 문장

화면 하단 중앙에 니체의 위버멘쉬·초월·자기극복 사상을 바탕으로 다듬은 365개의 문장이 날짜별로 표시됩니다. 좌우의 ‹ › 버튼은 넓은 클릭 영역으로 쉽게 선택할 수 있고 다른 문장도 볼 수 있으며 날짜가 바뀌면 그날의 문장으로 시작합니다. PC에서는 긴 문장도 한 줄로 볼 수 있도록 문장 영역을 넓게 사용합니다.

10. 백업·복원

허용된 계정 로그인이 필수입니다. 로그인하고 클라우드를 확인한 후에만 업무를 수정할 수 있습니다. 연결 오류나 오프라인에서는 마지막 데이터를 읽기 전용으로 표시합니다. 연결하면 클라우드에 저장하고 다른 기기에 실시간 반영합니다. 최초 연결에서는 양쪽 데이터를 백업하며 서로 다르면 선택창이 열립니다. 충돌이나 연결 오류는 상단 동기화 버튼으로 다시 확인하세요. 백업을 누르면 지원되는 Chrome/Whale 환경에서는 저장 위치 선택 창이 열리며 원하는 폴더와 파일명을 지정해 JSON으로 저장할 수 있습니다. 브라우저가 이 기능을 지원하지 않으면 일반 다운로드 방식으로 백업됩니다. 필요할 때 복원으로 불러오세요.
